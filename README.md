# Dynamic Island for Windows

A WPF Windows app that displays a Dynamic Island-style panel at the top of the screen.

## Download the EXE

1. Open the **Actions** tab.
2. Select **Build Dynamic Island EXE**.
3. Open the latest successful run.
4. Download the **DynamicIsland-Windows-x64** artifact.
5. Extract the ZIP and run `DynamicIsland.exe`.

The EXE is self-contained for Windows x64; a separate .NET runtime installation is not required.

## Local build

With the .NET 8 SDK installed on Windows, run `build.bat`. The EXE is written to `out\DynamicIsland.exe`.
